# legacy-slimies

The original Express + SQLite "Slimies" prototype (a shared slime pet with mood
sharing between two people), kept here for reference when this repository was
repurposed for ASCENDANT.

It is not part of the build, is excluded from linting, and nothing in the app
imports from it. To run it:

```bash
cd legacy-slimies
npm install
node server.js
```
